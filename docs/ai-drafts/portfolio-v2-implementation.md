# Portfolio V2 Implementation Notes (AI draft)

Repo: `core/projects/portfolio-v2` (local, no remote). Branches: phase-21 foundation, 22 about, 23 experience, 24 stack/process, 25 projects (each built on the previous).

Libraries added: `cmdk`, `@lucasmarkes/hairline` (MIT). Already present and reused: framer-motion, embla, lucide, reactflow v11, radix.
Deliberately not installed: Motion Primitives, Animate UI, React Bits, Magic UI, shiki, shadcn additions, Origin UI (overlap with framer-motion/existing components; no demonstrated need).

Decisions
- Content untouched: 12 projects, 22 achievements, 6 experiences, 12 process steps preserved.
- Project filters (Web/Mobile/Desktop/AI) are derived from technologies; only 6 projects declare a `category`, so it is not used for filtering.
- Architecture diagram only where the data documents it (Solace Hotel). SQM, AILead, others not drawn until repo docs are reviewed.
- Dev script uses `next dev --webpack`: Turbopack dev returned 404s for lazy chunks.

Not done
- Shiki code panels; Origin UI patterns.
- Orange remains only in the Light theme tokens (its own identity). Dark tone tokens were muted to subtle tints.
- Icons are a placeholder 'R' monogram (`app/icon.svg`, `app/apple-icon.png`), generated by the assistant; replace with real artwork.

Added in phase-26: ActivityLightbox (fullscreen viewer, arrows, Esc, counter) on the activities carousel; muted dark tone tokens; legacy dot grid hidden in dark theme; removed `background-attachment: fixed`.
Performance experiments that did NOT stick: `content-visibility: auto` on below-the-fold sections (large TBT gain, but broke anchor navigation: section landed 630px off); a load-time-only variant gave no measurable gain. Both reverted.

Added in phase-27: journey timeline (all years visible, type filters derived from icon/title, expandable details); navbar restyle (RHYSS wordmark, Ctrl K search button, aria-current, Esc closes mobile menu); command palette dialog title/description; placeholder favicon and apple icon.

Added in phase-28
- Standardized on Bun: npm and pnpm lockfiles removed, scripts/README use Bun, CI uses `oven-sh/setup-bun` with `bun install --frozen-lockfile`. Format check is advisory (`continue-on-error`) because ~200 existing files are not Prettier-formatted and the Prettier config references an uninstalled plugin; reformatting everything was out of scope. `unrs-resolver` postinstall left untrusted (not needed).
- Architecture diagrams added for Archon (from its public `docs/architecture-overview.md`) and the public SQM frontend demo (from its `project.md`, labelled as a frontend demo with mock data, not the production system). AILead has no repository, so no diagram.
- Contact form: removed two "respond within 24 hours" promises; success message now styled as success. The form needs `NEXT_PUBLIC_EMAILJS_SERVICE_ID`, `NEXT_PUBLIC_EMAILJS_TEMPLATE_ID`, `NEXT_PUBLIC_EMAILJS_PUBLIC_KEY` at build time (they are inlined at build); without them it shows the failure message.
- GitHub: private repo `uyronmarche14/portfolio-v2`, all branches pushed. GitHub Actions runs end in `startup_failure` even for a trivial probe workflow, so it is an account/repo-level cause (likely Actions billing or spending limit), not the workflow file. Needs checking in GitHub settings. CI has never actually run.
- Hosting: the live site is served through Cloudflare (response headers, Cloudflare IPs) and the last Portfolio commit mentions a Cloudflare Worker, but no wrangler/OpenNext config exists in the repo. Deployment config still needs to be written by the owner; nothing was deployed.

Not built (deliberate)
- Shiki code panels: no verified code snippets to show, so no dependency was added.
- Origin UI patterns: existing FilterTabs/cmdk cover the need.
